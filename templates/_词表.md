# 🏷️ 标签受控词表

> 新建笔记时**只从这里选**。要加新 tag，先加进本页再使用。

## 1. type/ — 必选，恰好 1 个

由**所在目录**决定，不用手填。

| tag | 目录 |
|-----|------|
| `type/daily` | `01_Daily/YYYY-MM/` |
| `type/weekly` | `02_Reports/周报/YYYY/` |
| `type/monthly` | `02_Reports/月报/YYYY/` |
| `type/meeting` | 会议纪要类 |
| `type/knowledge` | `03_Knowledge/` |
| `type/project` | `04_Projects/` |
| `type/moc` | `_MOC.md` / `_索引.md` / `_INBOX.md` / `_词表.md` / `_资产契约.md` |

校验口径：`sum(type 计数) == md 文件总数`，且每文件恰好 1 个 `type/`。
数量对不上，说明有笔记漏了 frontmatter 或写了两个 `type/`。

## 2. project/ — 可选，可多个

按你的实际项目填。命名用小写英文短横线，和 `04_Projects/` 下的目录名保持一致。

| tag | 含义 |
|-----|------|
| `project/<项目A>` | 一句话说明 |
| `project/<项目B>` | 一句话说明 |

## 3. 主题 tag — 可选

对应 `03_Knowledge/` 下的主题子目录，用于细化检索。

| tag | 含义 |
|-----|------|
| `<主题>/<子类>` | 例：`部署/docker` |

## 4. 禁止的写法

- ❌ 状态类：`待修` `待办` `排期` `milestone` `okr` —— 状态用正文 checkbox 表达，不用 tag。
- ❌ 一个文件多个 `type/`。
- ❌ 词表里没有的 tag。要加先加进本页。
