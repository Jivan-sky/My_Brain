# 技能: daily-report

## 使用方式
用户输入 `/daily-report`，汇总当日工作内容，写入 Obsidian 日报。

## 功能描述
通用的每日工作总结技能。不绑定任何特定项目——根据当天实际会话内容和工作产出生成日报。**默认精简版**，用户明确要求才扩写。

## Vault 位置

`{{VAULT_PATH}}`（目录约定见 `/obsidian-vault` skill）

## 执行流程

### 步骤 1：收集今日信息源
- 回顾当前对话会话中完成的事项
- 读取今日 `01_Daily/YYYY-MM/YYYY-MM-DD.md`（如 start-my-day 已创建，则合并）
- 检查 `04_Projects/` 中最近修改的文件

### 步骤 2：写入 Obsidian 日报
文件路径：`{{VAULT_PATH}}/01_Daily/YYYY-MM/YYYY-MM-DD.md`

**默认精简模板**：
```markdown
---
title: "YYYY-MM-DD 每日记录"
created: YYYY-MM-DD
tags:
  - type/知识捕获
  - daily
  - <项目tag>   # 从会话上下文推断，多个项目可多行
---

## ✅ 完成事项

### 🛠️ <项目A>
- **要点**：说明（动宾结构，开头加粗关键词）

### 🚚 <项目B>
- **要点**：说明

## 🧭 关键决策

- **决策要点** — 理由/说明

## ⏳ 遗留待办

- [ ] **事项**（原因/阻塞点）
- [x] 已完成事项（本日已补完的遗留）
- ~~废弃事项~~（被砍/改道）
```

**格式规则**：
- 章节标题用 emoji 前缀：`✅ 完成事项` / `🧭 关键决策` / `⏳ 遗留待办`。
- 「完成事项」按**项目分组**，`### 项目名` 子标题可配图标（如 🛠️ 开发 / 🚚 业务 / 📦 交付）。单项目可省子标题直接列 bullet。
- 完成事项 bullet 用「**加粗要点** + 说明」结构，扫描快。
- 关键决策用 `**决策** — 理由` 破折号格式；无决策则省略整节。
- 阻塞项不单列「阻塞」节——并进「遗留待办」，`（挂起）` / `（等接口）` / `（需 XX 权限）` 标注原因。
- 遗留待办 checklist 三态：`- [ ]` 未完成，`- [x]` 本日已补完，`~~划线~~` 废弃/改道；首词加粗。
- 没内容的节直接省略，不留空标题。
- 保持精简，默认 ≤ 30 行。用户要求详版才扩写。

**合并规则**（文件已由 start-my-day 创建时）：
- 保留「所属阶段」「今日目标」「今日待办」表格、「Inbox 待处理」不动。
- 追加「完成事项」「关键决策」「遗留待办」三节，并回填「今日待办」表格的状态列（✅/⬜）。
- frontmatter 补充项目 tag，保留已有 tag。

### 步骤 3：归档关键知识（可选）
如有值得长期保留的技术知识点/架构决策，写入 `03_Knowledge/` 对应文件。不超过每日 1 条。

## 交互确认点

|------|------|

写入后一句话确认：日报已写入 Obsidian。
